# 失敗記録の参照目次

この目次には人間が承認した記録だけを登録する。対策の結論ではなく、本文を読むトリガー条件とリンクを載せる。運用と登録方法は[README](README.md)を参照する。

## 照合のタイミング

| タイミング | トリガー条件と照合する情報 |
|---|---|
| 計画前・対象範囲の拡大時 | 対象パス、変更する契約、作業の種類 |
| エラー後、次の修正前 | エラー文、失敗した操作、症状。完全一致だけでなく同じ失敗の種類も確認する |
| 完了報告前 | 検証の種類、未実施事項、成功の判定条件 |

該当する記録は本文を読む。読了済みで本文が未変更なら再読込は不要だが、現在の適用条件を再確認する。該当なしの場合も通常の調査・検証を行う。

## 承認済み記録

現在、承認済み記録はない。承認後、次の形式で登録する。

```markdown
| ID | 本文を読むトリガー条件 | 詳細 |
|---|---|---|
| LESSON-001 | 対象パス、作業内容、エラーの特徴を具体的に記載 | [本文](approved/LESSON-001.md) |
```

PR・コミット単位の証拠一覧や `<details>` は詳細本文に置く。折りたたみを読了・遵守の保証として扱わない。
