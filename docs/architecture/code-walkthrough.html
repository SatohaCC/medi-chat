04 / UI & EVENTS

根拠と本文は、別々のイベントで届く。

retrieval_status→sources（複数回の場合あり）→text_delta × N→text_done

通常経路の概略。確認要求・Jev未利用などで省略されるイベントがあり、Jev利用時にはjev_responseも送信されます。

イベントバックエンドの意味フロントエンドの扱い
sources途中の累積根拠、または最終根拠最新assistantのsourcesを置換。受信ごとに追記して重複を増やさない。
text_delta生成本文の断片最新assistantのcontentへ追加。
retrieval_status / jev_response検索進行と分類の情報本文と別のメッセージ属性を更新。
text_done / error完了、または処理失敗進行中の要求と生成中フラグを解除。
